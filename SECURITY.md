# Security policy — source preview

This candidate is not production certified. Do not upload secrets or sensitive diagnostics to a public issue.

Maintainer: [TorofSkiy](https://github.com/TorofSkiy). Private vulnerability reporting and a response-time commitment are not yet configured for this preview. If a private reporting option is unavailable, open an issue asking the maintainer for a private channel, without vulnerability details, credentials, personal information or exploit material. Wait for that channel before sharing sensitive details.

Supported review target: Windows 11 x64 native core, version 0.4.0-network.2. Other platforms and deployed production configurations are outside this snapshot.

Dependency updates require lockfile review, build/test evidence and a new immutable release. Keep platform security enabled. Source hashes detect changes but do not authenticate an unknown publisher. No bypass instructions are provided for blocked executables.

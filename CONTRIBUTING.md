# Contributing

This is an Apache-2.0 source preview maintained by [TorofSkiy](https://github.com/TorofSkiy). Use this repository's issues and pull requests for non-sensitive contributions. Independent review and release-signing roles are not yet established.

Contribution process:
- Contributions must be licensed under the project's approved Apache-2.0 license and be owned by the contributor or used with permission.
- Discuss compatibility and user-visible behavior before broad changes. Keep OS integration behind documented adapters.
- Never submit production config, device identifiers, secrets, model weights, private documents or deployment history.
- Run the pinned build and relevant behavioral tests. Include the exact scope and limitations of tests; never describe a local test as physical-target validation.
- Human review is required for source, dependencies, permission changes and releases. Automated agents can propose and test changes; they cannot authorize new paid resources or override release policy.
- Use MFA; keep release approvers separate from automated submitter credentials. Name actual people/handles before enabling signing.
- Preserve third-party notices and document data collection, network destinations and removal behavior.

Cross-platform adapters are future work. Native Windows code does not establish support for other kernels, mobile platforms or industrial real-time systems.
